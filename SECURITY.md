# Security Policy

## Supported Versions

The versions below marked with a check mark are supported, if marked with a red x they are not supported.

| Version | Supported          |
| ------- | ------------------ |
| v0.7.0  | :white_check_mark: |

## Reporting a Vulnerability

You can report a vulnerability on the support page, which is https://support.essie.dev.

Every report is added to a database, and when it is resolved, we will send you an email. In this email, you can request your data to be fully deleted from the form and database. If you think data is already on our forms and want it deleted, you can request your data to be deleted at support@essie.dev.
