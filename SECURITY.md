## Reporting a Vulnerability

You can report a Vulnerability at the support page, which is https://support.essie.dev.

Every report is added to a data base, and when it is resolved we will send you an email. In this email you can request your data to be deleted full from the form and data base. If you think data is already on our forms and want it deleted you can request your data to be deleted at support@essie.dev.
